# sdlc-docs-jp

日本語によるソフトウェア開発ライフサイクル（SDLC）のドキュメンテーションテンプレート集です。

## 概要

このリポジトリは、ソフトウェア開発プロジェクトで使用するための標準化されたドキュメントテンプレートを提供します。各フェーズごとにテンプレートを用意しており、プロジェクトの要件定義から詳細設計まで対応しています。

## ディレクトリ構造

```
.
├── README.md                              # このファイル
├── SKILL.md                               # スキル定義書
└── assets/                                # ドキュメントテンプレート
    ├── 00_raw_notes_template.md           # 生ノートテンプレート
    ├── 01_requirements_spec_template.md   # 要件仕様書テンプレート
    ├── 02_requirements_definition_template.md  # 要件定義書テンプレート
    ├── 03_basic_design_template.md        # 基本設計書テンプレート
    └── 04_detailed_design_template.md     # 詳細設計書テンプレート
```

## 提供テンプレート

1. **生ノートテンプレート** (`00_raw_notes_template.md`)
   - プロジェクト開始時の生のメモやアイデアをまとめるテンプレート

2. **要件仕様書テンプレート** (`01_requirements_spec_template.md`)
   - クライアントやステークホルダーの要件をまとめるテンプレート

3. **要件定義書テンプレート** (`02_requirements_definition_template.md`)
   - ビジネス要件と機能要件を詳細に定義するテンプレート

4. **基本設計書テンプレート** (`03_basic_design_template.md`)
   - システムの全体構成とアーキテクチャを設計するテンプレート

5. **詳細設計書テンプレート** (`04_detailed_design_template.md`)
   - モジュール、データベース、インターフェースなど詳細な設計を定義するテンプレート

## 使用方法

1. 必要なテンプレートを `assets/` ディレクトリから選択します
2. テンプレートをプロジェクトディレクトリにコピーします
3. プロジェクト固有の情報を入力して使用します

## ブランチ戦略

- `main`: リリース版ドキュメント
- `develop`: 開発版ドキュメント
- `feature/*`: 新機能やテンプレート追加
